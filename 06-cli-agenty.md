# Топик 5. CLI и терминальные ИИ-агенты

Многие дизайнеры никогда не открывали терминал (командную строку) и воспринимают его как «территорию разработчиков». Но именно в терминале сегодня работают самые мощные ИИ-агенты для создания продуктов — и для дизайнера, который серьёзно занимается вайбкодингом, освоить базовые команды стоит того: терминальные агенты видят весь проект целиком (а не один файл, вставленный в чат), сами запускают и проверяют результат, и умеют работать с git — системой версий, в которой хранится история изменений кода (подробнее про git — в топике «Вайбкодинг»).

**CLI** (command line interface) — это интерфейс, где вместо кнопок вы печатаете текстовые команды и получаете текстовый ответ. Установка происходит один раз через специальную команду, после чего инструмент запускается прямо из папки с проектом.

## Claude Code (Anthropic)

Установка (macOS/Linux):
```
curl -fsSL https://claude.ai/install.sh | bash
```
Запуск в папке проекта:
```
cd my-project
claude
```
После этого можно сразу писать задачу на обычном языке:
```
claude "напиши тесты для модуля авторизации, запусти их и почини всё, что не проходит"
```
Claude Code умеет работать в «трубе» (pipe) с другими командами — например, скормить ему лог ошибок и попросить проанализировать:
```
tail -200 app.log | claude -p "скажи, если видишь в логах что-то подозрительное"
```

## Codex CLI (OpenAI)

Установка:
```
npm install -g @openai/codex
```
Запуск и постановка задачи:
```
codex "добавь переключатель тёмной темы на главный экран"
```
Codex CLI также принимает изображения — можно передать скриншот макета:
```
codex --image "./screens/homepage.png"
```

## Gemini CLI (Google)

Установка:
```
npm install -g @google/gemini-cli
```
Запуск интерактивной сессии в текущей папке:
```
gemini
```
Или разовый вопрос без диалога:
```
gemini -p "объясни структуру этого проекта простыми словами"
```

## Как этим пользоваться дизайнеру

Дизайнеру не обязательно становиться разработчиком, чтобы этим пользоваться: базовый сценарий — скачать/открыть готовый проект (например, сгенерированный в v0 или Figma Make), открыть терминал в этой папке и естественным языком попросить агента что-то поправить: перекрасить кнопку, поправить отступы, добавить анимацию. Разница с обычным веб-чатом в том, что агент реально видит и правит все файлы проекта сразу, а не один фрагмент кода, вставленный вручную.

Отдельно стоит объяснить «режимы одобрения»: по умолчанию агент спрашивает подтверждение перед каждым действием (создать файл, удалить строку, выполнить команду), но можно включить более автономный режим, где агент действует без остановок на каждом шаге — это быстрее, но требует больше доверия к задаче и обязательной проверки результата в конце.

## Примеры команд для практики

- «Объясни, что делает эта команда, прежде чем я её запущу: `codex --approval-mode full-auto "почисти неиспользуемый код"`»
- «Я впервые открываю терминал — распиши по шагам, что нажимать, чтобы установить и запустить Claude Code на Mac.»
- «Вот ошибка из терминала (вставить текст ошибки) — объясни простыми словами, что пошло не так.»
